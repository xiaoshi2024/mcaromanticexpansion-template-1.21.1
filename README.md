# MCA Romantic Expansion

MCA Romantic Expansion 是 Minecraft Comes Alive (MCA) 模组的扩展，让你可以直接使用 MCA 的花束、订婚戒指、结婚戒指右键玩家进行浪漫互动！

## 功能特性

- **花束互动**：使用 MCA 花束右键玩家，对方可以选择收下或拒收
- **订婚系统**：使用 MCA 订婚戒指右键玩家发送求婚请求（只需一方有戒指）
- **结婚系统**：使用 MCA 结婚戒指右键玩家进行婚礼（双方都需要拥有结婚戒指）
- **戒指交换**：结婚时双方交换戒指，就像真实婚礼一样
- 完全集成 MCA 已有的关系管理系统

## 如何使用

### 物品交互流程

1. **获得 MCA 物品**
   - 花束 (Bouquet)
   - 订婚戒指 (Engagement Ring)
   - 结婚戒指 (Wedding Ring)

2. **花束互动**
   - 右键其他玩家使用花束
   - 对方会看到「收到花束」GUI
   - 点击「收下」：花束从赠送者背包转移到受礼者背包
   - 点击「拒收」：花束留在赠送者背包

3. **订婚流程**
   - 右键其他玩家使用订婚戒指
   - 对方会看到「求婚」GUI
   - 点击「我愿意！」：订婚戒指从求婚者转移到接受者，正式订婚
   - 点击「抱歉，不能」：拒绝求婚

4. **结婚流程**（双方都需要结婚戒指）
   - 右键其他玩家使用结婚戒指
   - 对方会看到「婚礼仪式」GUI
   - 点击「交换戒指」：双方交换戒指并正式结婚
   - 点击「取消」：取消婚礼

5. **使用 MCA 命令进行更多操作**
   - `/mca proposals` - 查看你的求婚列表
   - `/mca accept <玩家>` - 接受某人的求婚
   - `/mca reject <玩家>` - 拒绝某人的求婚
   - `/mca separate` - 离婚

## 核心原理

这个模组直接调用 MCA 已有的完整系统：

- **ServerInteractionManager** - MCA 的玩家关系管理器
- **PlayerSaveData** - MCA 的玩家数据存储
- **物品系统** - 使用 MCA 已有的花束、订婚戒指、结婚戒指

## 结婚戒指交换机制

结婚戒指的交互设计参考了真实婚礼的仪式：

1. **条件要求**：双方玩家都必须拥有至少一个结婚戒指
2. **交换过程**：
   - 玩家 A 使用结婚戒指右键玩家 B
   - 玩家 B 接受后，系统会从双方背包中各取走一个戒指
   - 然后将玩家 A 的戒指放入玩家 B 的背包
   - 将玩家 B 的戒指放入玩家 A 的背包
3. **意义**：象征着双方在婚姻中的承诺和结合

## 要求

- Minecraft 1.21.1
- NeoForge
- **Minecraft Comes Alive Reborn (MCA)** - 必须安装

## 安装

1. 下载 MCA Romantic Expansion 模组
2. 放入你的 `mods` 文件夹
3. 确保 MCA 模组也已安装
4. 使用 NeoForge 启动游戏
